# Semantic colors

Set the semantic color with `color`, which defaults to `warning`.

## Source

```vue
<template>
  <am-flex vertical gap="small">
    <am-notice-bar color="default" content="default: a neutral notice" />
    <am-notice-bar color="info" content="info: an info notice" />
    <am-notice-bar color="success" content="success: a success notice" />
    <am-notice-bar color="warning" content="warning: a warning notice" />
    <am-notice-bar color="error" content="error: an error notice" />
  </am-flex>
</template>
```
