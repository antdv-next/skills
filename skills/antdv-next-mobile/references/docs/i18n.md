---
title: Internationalization
---

The built-in texts of the components are in Simplified Chinese by default. Switch the language through the `locale` of `ConfigProvider`; the usage is the same as on PC.

```vue
<script setup lang="ts">
import enUS from '@antdv-next/mobile/locale/en_US'
</script>

<template>
  <am-config-provider :locale="enUS">
    <App />
  </am-config-provider>
</template>
```

## Built-in locales

| Language | File |
| --- | --- |
| Simplified Chinese | `@antdv-next/mobile/locale/zh_CN` |
| English | `@antdv-next/mobile/locale/en_US` |

## Static methods

Static methods such as `Modal.confirm` and `Toast` are not part of the component tree; set their locale with `ConfigProvider.config`:

```ts
import { ConfigProvider } from '@antdv-next/mobile'
import enUS from '@antdv-next/mobile/locale/en_US'

ConfigProvider.config({ locale: enUS })
```

## Custom locale

A locale is a plain object and can be extended from a built-in one:

```ts
import type { Locale } from '@antdv-next/mobile'
import zhCN from '@antdv-next/mobile/locale/zh_CN'

const zhTW: Locale = {
  ...zhCN,
  locale: 'zh-tw',
  common: { ...zhCN.common, confirm: '確定', cancel: '取消' },
}
```

Date components use dayjs, so remember to switch the dayjs locale as well:

```ts
import dayjs from 'dayjs'
import 'dayjs/locale/en'

dayjs.locale('en')
```

## Use in your own components

```ts
import { useLocale } from '@antdv-next/mobile'

const locale = useLocale('Modal')
locale.value.okText // '确定'
```
