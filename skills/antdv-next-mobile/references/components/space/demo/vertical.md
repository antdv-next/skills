# Vertical space

Use `orientation="vertical"` or `vertical` for spacing in the vertical direction.

## Source

```vue
<template>
  <am-space vertical>
    <am-button type="primary">
      Button 1
    </am-button>
    <am-button>Button 2</am-button>
    <am-button>Button 3</am-button>
  </am-space>
</template>
```
