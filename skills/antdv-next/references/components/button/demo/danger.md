# 危险按钮

## Description (zh-CN)

在 4.0 之后，危险成为一种按钮属性而不是按钮类型。

## Source

```vue
<template>
  <a-flex wrap gap="small">
    <a-button type="primary" danger>
      Primary
    </a-button>
    <a-button danger>
      Default
    </a-button>
    <a-button type="dashed" danger>
      Dashed
    </a-button>
    <a-button type="text" danger>
      Text
    </a-button>
    <a-button type="link" danger>
      Link
    </a-button>
  </a-flex>
</template>
```
