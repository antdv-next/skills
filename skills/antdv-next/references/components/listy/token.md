# listy Token

Use these variables through `theme.components.Listy`. This document lists definitions only and does not include values.

```vue
<a-config-provider
  :theme="{
    token: {
      // Global token configuration
    },
    components: {
      Listy: {
        // Token name: value
      },
    },
  }"
>
  ...
</a-config-provider>
```

## Token List

| Token | Type | Description |
| --- | --- | --- |
| `itemPaddingBlock` | `number` | Vertical padding of a list item. |
| `itemPaddingInline` | `number` | Horizontal padding of a list item. |
