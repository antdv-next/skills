title: ColorPicker
description: Pick a color by dragging in a bottom panel, with alpha, preset colors and several formats.

## When To Use

- When the user needs to customize a color (theme color, tag color, brush color ...).
- Use `ColorPickerPanel` to embed the color panel directly in a page.

The API is aligned with `ColorPicker` of Antdv Next: `value` is a color string or a `Color` object, `valueFormat` decides what `v-model:value` receives, and `format` decides how the inputs and the text display the color. On mobile a bottom popup replaces the dropdown panel, and the color is committed after tapping "OK".

## API

### ColorPicker Props

| Prop | Description | Type | Default |
| --- | --- | --- | --- |
| value (v-model) | The committed color; `null` / an empty string means no color | `string \| Color \| null` | - |
| defaultValue | Default color (uncontrolled) | `string \| Color \| null` | - |
| valueFormat | Output format of `v-model:value`: a string in that format when set, a `Color` object otherwise | `'hex' \| 'rgb' \| 'hsb' \| ((color: Color) => string)` | - |
| format (v-model) | Color format of the inputs and the trigger text | `'hex' \| 'rgb' \| 'hsb'` | - |
| defaultFormat | Default color format (uncontrolled) | `'hex' \| 'rgb' \| 'hsb'` | `'hex'` |
| allowClear | Show a clear button in the panel | `boolean` | `false` |
| disabled | Whether it is disabled | `boolean` | `false` |
| disabledAlpha | Disable alpha | `boolean` | `false` |
| disabledFormat | Disable switching the color format | `boolean` | `false` |
| open (v-model) | Whether the popup is open | `boolean` | - |
| defaultOpen | Whether it is open by default | `boolean` | `false` |
| presets | Groups of preset colors | [ColorPickerPresetsItem](#presets-item)[] | - |
| showText | Show the color text, or render it; the same-named slot wins | `boolean \| ((info: { color: Color }) => VNodeChild)` | `false` |
| size | Size of the trigger | `'small' \| 'middle' \| 'large'` | `'middle'` |
| panelRender | Custom panel content; the same-named slot wins | `(info: { panel: VNode, extra: { components: { Picker, Presets } } }) => VNodeChild` | - |
| destroyOnHidden | Unmount the popup content when closed | `boolean` | `false` |
| title | Title of the popup; the same-named slot wins | `VueNode` | - |
| okText | Text of the confirm button | `string` | `'OK'` |
| cancelText | Text of the cancel button | `string` | `'Cancel'` |
| getContainer | Mount node of the popup; `false` renders in place | `string \| HTMLElement \| (() => HTMLElement) \| false` | `document.body` |
| zIndex | z-index of the popup | `number` | - |
| maskClosable | Whether tapping the mask closes it (same as cancel) | `boolean` | `true` |
| id | id of the trigger, defaults to the id generated by FormItem | `string` | - |
| rootClass | Class of the trigger and of the popup root | `string` | - |
| classes | Semantic classes: `root`, `body`, `content`, `description`, `popup` | `ColorPickerSemanticClassNames` | - |
| styles | Semantic styles | `ColorPickerSemanticStyles` | - |

### ColorPicker Events

| Event | Description | Type |
| --- | --- | --- |
| update:value | The committed color changed | `(value: string \| Color \| null) => void` |
| change | The committed color changed (OK tapped) | `(color: Color, css: string) => void` |
| changeComplete | A drag ended, or a non-drag change happened (preset, input ...); the color is not committed yet | `(color: Color) => void` |
| select | The pending color of the panel changed (continuously while dragging), not committed yet | `(color: Color, css: string) => void` |
| confirm | OK tapped | `(color: Color) => void` |
| cancel | Cancel or the mask tapped | `() => void` |
| clear | The committed color was cleared | `() => void` |
| formatChange | The color format changed | `(format: 'hex' \| 'rgb' \| 'hsb') => void` |
| update:format | The color format changed | `(format: 'hex' \| 'rgb' \| 'hsb') => void` |
| openChange | The popup opened / closed | `(open: boolean) => void` |
| update:open | The popup opened / closed | `(open: boolean) => void` |

### ColorPicker Slots

| Slot | Description | Params |
| --- | --- | --- |

### ColorPicker Methods

| Method | Description | Type |
| --- | --- | --- |
| toggle | Toggle the popup, optionally to a given state | `(open?: boolean) => void` |

### ColorPickerPanel Props

The inline panel has no trigger and no popup, and color changes take effect immediately. It supports `value (v-model)`, `defaultValue`, `valueFormat`, `format (v-model)`, `defaultFormat`, `allowClear`, `disabled`, `disabledAlpha`, `disabledFormat`, `presets`, `panelRender` and `rootClass` with the same meaning as above.

| Prop | Description | Type | Default |
| --- | --- | --- | --- |
| classes | Semantic classes: `root`, `palette`, `slider`, `input`, `presets` | `ColorPickerPanelSemanticClassNames` | - |
| styles | Semantic styles | `ColorPickerPanelSemanticStyles` | - |

### ColorPickerPanel Events

| Event | Description | Type |
| --- | --- | --- |
| update:value | The color changed | `(value: string \| Color \| null) => void` |
| change | The color changed, continuously while dragging | `(color: Color, css: string) => void` |
| changeComplete | A drag ended, or a non-drag change happened | `(color: Color) => void` |
| clear | Clear tapped | `() => void` |
| formatChange | The color format changed | `(format: 'hex' \| 'rgb' \| 'hsb') => void` |
| update:format | The color format changed | `(format: 'hex' \| 'rgb' \| 'hsb') => void` |

Slot: `panelRender`, same as ColorPicker.

| Prop | Description | Type | Default |
| --- | --- | --- | --- |
| label | Title of the group | `VueNode` | - |
| colors | List of colors | `(string \| Color)[]` | - |
| defaultOpen | Whether it is expanded by default | `boolean` | `true` |
| key | Key of the group | `string \| number` | - |

### Color

The color object handed to the events, `showText` and `v-model:value` (without `valueFormat`), same as Antdv Next.

| Member | Description | Type |
| --- | --- | --- |
| toHexString | `#rrggbb`, or `#rrggbbaa` with alpha | `() => string` |
| toRgbString | `rgb(r,g,b)` or `rgba(r,g,b,a)` | `() => string` |
| toHsbString | `hsb(h, s%, b%)` or `hsba(h, s%, b%, a)` | `() => string` |
| toCssString | A string usable in CSS (same as `toRgbString`) | `() => string` |
| toHex | Hex string without the `#` | `() => string` |
| toRgb | RGB object | `() => { r, g, b, a }` |
| toHsb | HSB object (`s`, `b`, `a` are 0 - 1) | `() => { h, s, b, a }` |
| equals | Whether it is the same color | `(color?: Color \| null) => boolean` |
| cleared | Whether it is "no color" | `boolean` |

Color strings support 3 / 4 / 6 / 8 digit hex, `rgb()` / `rgba()`, `hsb()` / `hsba()` and `hsl()` / `hsla()`.

## Differences from PC

- A bottom popup with "Cancel / OK" in its header replaces the dropdown panel: dragging, typing and tapping a preset only change a pending color and fire `select`; the color is committed and `change` / `update:value` fire after tapping "OK" (consistent with the other pickers of this library). `changeComplete` still fires when a drag ends, but the color is not committed at that point. Adds the `select`, `confirm`, `cancel` events and the `toggle()` method.
- `clear` fires once the cleared color is committed (OK tapped); the inline `ColorPickerPanel` has no pending state, so its `change` and `clear` fire immediately.
- Gradient mode (`mode: 'gradient'`) is not supported: the value type has no gradient array, `Color` has no `isGradient()` / `getColors()`, and the `singleColor` / `gradientColor` locale texts are unused for now.
- No `trigger` (there is no hover on mobile), `placement`, `arrow` or `autoAdjustOverflow`; the popup container uses `getContainer` (same as Popup), `getPopupContainer` is not supported.
- The format switch is a Segmented instead of a dropdown Select; the number inputs have no stepper buttons; the clear button is a button with text.
- Adds mobile props: `title`, `okText`, `cancelText`, `maskClosable`, `zIndex`, `defaultOpen`, `id`, as well as the embeddable `ColorPickerPanel` (`ColorPicker.Panel`).
- The default slot is a scoped slot `{ open, value, label, disabled, toggle }`; call `toggle()` yourself to open the popup.
- `classes` / `styles` only accept objects: `root`, `body`, `content`, `description`, `popup` for ColorPicker (`popup` is the popup body, there is no `popup.root` / `popup.container`); `root`, `palette`, `slider`, `input`, `presets` for ColorPickerPanel.
- The color model is built in and produces the same strings as PC; color names (such as `red`) are not supported, and out-of-range `rgb()` channels are clamped to 0 - 255.
- In RTL the palette and the sliders keep their physical direction and are not mirrored.
