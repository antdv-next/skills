# Line style

Set the line style with `variant`: solid, dashed or dotted.

## Source

```vue
<template>
  <am-divider variant="solid">
    Solid
  </am-divider>
  <am-divider variant="dashed">
    Dashed
  </am-divider>
  <am-divider variant="dotted">
    Dotted
  </am-divider>
  <am-divider dashed />
</template>
```
