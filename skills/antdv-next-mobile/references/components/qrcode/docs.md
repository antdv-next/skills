## When To Use

- Used when text or a link needs to be converted into a QR code, e.g. sharing a page, payment codes or scan-to-login.
- The QR code is generated by a built-in encoder (versions 1-40, error levels L / M / Q / H) without any third-party library.

## API

### Props

| Property | Description | Type | Default |
| --- | --- | --- | --- |
| value | Scanned text, an array is encoded as several segments; nothing is rendered when it is empty | `string \| string[]` | - |
| type | Render type | `'canvas' \| 'svg'` | `'canvas'` |
| icon | Url of the image in the QR code (only image urls are supported) | `string` | - |
| iconSize | Size of the image in the QR code (px) | `number \| { width: number, height: number }` | `40` |
| size | Size of the QR code (padding and border included): a number (px) or any CSS length such as `'100%'`, `'60vw'` | `number \| string` | `160` |
| color | Color of the QR code | `string` | Follows the theme, `--am-qrcode-color` |
| bgColor | Background color of the QR code | `string` | Follows the theme, `--am-qrcode-bg` |
| marginSize | Quiet zone in modules, `0` means no margin | `number` | `0` |
| bordered | Whether it has a border (turning it off also removes the padding and radius) | `boolean` | `true` |
| errorLevel | Error correction level | `'L' \| 'M' \| 'Q' \| 'H'` | `'M'` |
| boostLevel | Raise the error correction level when it does not increase the version, so the result may use a higher level than specified | `boolean` | `true` |
| status | Status of the QR code | `'active' \| 'expired' \| 'loading' \| 'scanned'` | `'active'` |
| statusRender | Custom status renderer, the same-named slot takes precedence | `(info: QRCodeStatusRenderInfo) => VueNode` | - |
| title | Accessible title of the QR code | `string` | - |
| rootClass | Class name of the root node | `string` | - |
| classes | Semantic structure class names | `Record<'root' \| 'cover', string>` | - |
| styles | Semantic structure styles | `Record<'root' \| 'cover', CSSProperties>` | - |

### Events

| Event | Description | Type |
| --- | --- | --- |
| refresh | Triggered when the refresh action of the expired state is tapped; the action only shows up when this event is listened to | `() => void` |

### Slots

| Slot | Description | Params |
| --- | --- | --- |
| statusRender | Custom status renderer, takes precedence over the `statusRender` prop | `QRCodeStatusRenderInfo` |

```ts
interface QRCodeStatusRenderInfo {
  status: 'expired' | 'loading' | 'scanned'
  locale: { expired: string, refresh: string, scanned: string }
  /** Only present when the `refresh` event is listened to */
  onRefresh?: () => void
}
```

### Methods

Called on the component instance obtained through `ref`.

| Method | Description | Type |
| --- | --- | --- |
| nativeElement | The root element | `HTMLDivElement` |
| toDataURL | Data URL of the QR code image, to save or share it. `canvas` equals `canvas.toDataURL(type, quality)` (PNG by default); `svg` returns an `image/svg+xml` image | `(type?: string, quality?: number) => string \| undefined` |

### Encoder

The built-in encoder can be used on its own, e.g. to draw the code yourself.

```ts
import { encodeQRCode } from '@antdv-next/mobile'

const { version, size, errorLevel, mask, modules } = encodeQRCode('https://www.antdv-next.com', {
  errorLevel: 'M', // minimum error correction level
  boostLevel: true,
})
// modules[y][x] === true is a dark module
```

## Differences from PC

- No `@v-c/qrcode` dependency: the QR code is generated by a built-in encoder, which is also exported as `encodeQRCode`.
- `size` also accepts a CSS length (such as `100%`); the QR code always stays square and is redrawn for its real width and the device pixel ratio.
- The defaults of `color` and `bgColor` come from theme variables (`--am-qrcode-color` / `--am-qrcode-bg`), so dark mode gives a light code on a dark background. Some scanners do not read inverted codes: set `color="#000"` and `bg-color="#fff"` explicitly for the best compatibility (or when exporting the image).
- New instance method `toDataURL()` to save or share the image without querying the inner `canvas` / `svg` node; the exported image carries the resolved foreground and background colors.
- `iconSize` is relative to the real pixel size of the QR code content; in `canvas` mode the center modules are only removed once the image has loaded, so a broken image leaves no hole.
- The loading indicator of the status cover is the built-in Spinner and the refresh action is a touch friendly link button.
- `classes` / `styles` only accept objects, not functions; the component level `class` / `style` of ConfigProvider is not supported.
- PC-only usages such as the Popover based hover demo are dropped.

## FAQ

### About the error correction level

The error correction level is the maximum share of the code that can be covered while it still scans: about `7%` for `L`, `15%` for `M`, `25%` for `Q` and `30%` for `H`. `L` is not recommended together with `icon`. For short content, `boostLevel` automatically uses a higher level without making the code bigger.

### The QR code cannot be scanned?

Long content makes the modules too dense: increase `size` or shorten the content with a short link. In dark mode, set black and white colors explicitly as described above. Content beyond the capacity of version 40 cannot be encoded; the component renders nothing and logs an error.
