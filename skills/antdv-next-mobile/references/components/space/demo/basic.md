# Basic usage

Keep a unified horizontal spacing between adjacent components.

## Source

```vue
<template>
  <am-space>
    <am-button type="primary">
      Primary
    </am-button>
    <am-button>Default</am-button>
    <am-button type="dashed">
      Dashed
    </am-button>
    <am-button type="link">
      Link
    </am-button>
  </am-space>
</template>
```
