# Basic

Wrap any container with `BorderBeam` to add a continuous decorative beam along its border. The beam layer is rendered inside the container, no wrapper element is added.

## Source

```vue
<template>
  <am-border-beam>
    <am-card title="Workspace overview">
      Review task status, deployment health and recent automation activity in one panel.
    </am-card>
  </am-border-beam>
</template>
```
