# Button type

Use the preset styles through the `type` syntactic sugar: primary, default, dashed, text and link buttons.

## Source

```vue
<template>
  <am-flex gap="small" wrap>
    <am-button type="primary">
      Primary
    </am-button>
    <am-button>Default</am-button>
    <am-button type="dashed">
      Dashed
    </am-button>
    <am-button type="text">
      Text
    </am-button>
    <am-button type="link">
      Link
    </am-button>
  </am-flex>
</template>
```
